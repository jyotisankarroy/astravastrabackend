# Cart Service

Manages active user shopping carts, adding/removing items, cart merging (anonymous to logged-in user), and cart persistence.

## Core Features & Responsibilities
- **Tech Stack Suggestion**: Redis / DynamoDB, Node.js or Go.
- **Key Features**: Low latency cart updates, guest cart retention, and cart synchronization.
