# Notification Service

Asynchronous service that consumes events (from Kafka/RabbitMQ) and sends emails, SMS messages, and push notifications to users.

## Core Features & Responsibilities
- **Tech Stack Suggestion**: Node.js or Spring Boot with SendGrid, Twilio, and Firebase Cloud Messaging.
- **Key Features**: Dynamic email templating, retry mechanisms, multi-channel notification support, and preference configuration.
