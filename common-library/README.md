# Common Library

A shared package containing utility classes, core domain DTOs, logging configurations, global exception handling advice, and reusable helper functions used across multiple microservices.

## Core Features & Responsibilities
- **Usage**: Compiled as a dependency (e.g., Maven dependency or NPM package) and imported by other services.
- **Key Features**: Reusable middlewares, security context helper utilities, standard error model schemas, and JSON parsing helpers.
