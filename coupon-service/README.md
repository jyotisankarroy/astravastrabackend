# Coupon & Promotion Service

Applies discounts, tracks promotional campaigns, validates coupon codes, and calculates total cart savings based on complex business rules.

## Core Features & Responsibilities
- **Tech Stack Suggestion**: PostgreSQL, Redis.
- **Key Features**: Dynamic coupon rule engine, coupon usage limits, dynamic discounts (percentage/flat rate), and campaign tracking.
