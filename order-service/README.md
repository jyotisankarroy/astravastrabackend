# Order Service

Orchestrates order placement, order state machine (Created, Paid, Shipped, Delivered, Cancelled), invoice generation, and order history tracking.

## Core Features & Responsibilities
- **Tech Stack Suggestion**: PostgreSQL, Spring Boot / Go (utilizing Saga Pattern or State Machine).
- **Key Features**: Checkout flow orchestration, order status tracking, transactional outbox pattern, and invoice generation.
