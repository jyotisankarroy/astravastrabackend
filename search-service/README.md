# Search Service

Powers fast, relevant search and filtering across the product catalog. Synchronizes catalog data via message brokers into search indexes.

## Core Features & Responsibilities
- **Tech Stack Suggestion**: Elasticsearch, OpenSearch, or Meilisearch.
- **Key Features**: Full-text search, auto-completion, faceted filtering (brand, price, ratings), and typo tolerance.
